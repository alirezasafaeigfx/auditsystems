# Two-Minute Sample Report Demo Script

Status: public-safe demo support for `auditsystems#26`.

1. Open `/sample-report` and state that the domain is anonymized and no customer data is shown.
2. Start with the executive summary: show total findings, confirmed findings, and hypotheses separately. Do not claim fake ranking, revenue, or speed numbers.
3. Pick one high-severity confirmed finding. Read the evidence, business impact, recommendation, and priority.
4. Pick one hypothesis finding. Explain that it needs validation with a real run or field data before making a final performance claim.
5. Show the 30-day action plan: first fix P0/P1 risks, then validate performance hypotheses, then prepare before/after evidence and monitoring.
6. End on the CTA: `Request assessment`, which opens `/qualification` and captures source, placement, offer, consent, and business context.

Public safety checklist:

- No secret, customer name, private IP, admin URL, token, cookie, or infrastructure detail appears.
- No guaranteed ranking, revenue, or conversion outcome is stated.
- Every shown finding has severity, evidence, impact, recommendation, and priority.
