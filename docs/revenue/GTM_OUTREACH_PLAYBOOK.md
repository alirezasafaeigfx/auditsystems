# Audit GTM Execution Pack

Status: preparation only for `auditsystems#28`. Do not send external outreach without owner approval.

## Qualification Rubric

Qualified prospect:

- active public website
- commercial or agency use case
- visible technical issue that can be evidenced from public pages
- reachable business contact path
- likely benefit from Entry Audit or Full Technical Audit

Disqualified prospect:

- no public site
- no relevant business owner/contact
- asks for guaranteed ranking or revenue
- requires private/security-sensitive testing before contract
- unrelated to ASDEV Audit acquisition or revenue

## 50-Prospect Register Fields

Store privately or in an approved CRM, not in a public repository:

- company
- website
- segment
- contact path
- country/language
- observed public issue
- evidence URL
- proposed offer
- source
- owner
- status: new, researched, contacted, positive, call, proposal, won, lost
- next action date
- rejection/loss reason

## Three-Finding Mini-Audit Template

For each selected prospect:

1. Finding title
2. Severity
3. Public evidence
4. Likely business impact
5. One recommended next step
6. Confidence: confirmed or hypothesis

## Outreach Template

Subject: Quick technical finding on [site]

Hi [name],

I reviewed [specific page] and noticed [specific evidence]. The likely impact is [impact], especially for [business context].

I can turn this into a short ASDEV Audit with priority findings and a 30-day action plan. If useful, I can walk through it in 20 minutes.

No pricing is public yet; the next step is a request assessment so scope is clear first:
[qualification link with source/placement/offer]

## Follow-Up Template

Hi [name],

Following up once on the [finding] note. If this is not a priority, no problem. If it is, the useful next step is a scoped assessment so we can separate confirmed issues from hypotheses before proposing fixes.
