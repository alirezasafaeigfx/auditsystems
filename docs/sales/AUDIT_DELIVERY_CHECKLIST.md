# Audit Delivery Checklist

## Pre-delivery
- [ ] Audit run completed successfully (status: SUCCEEDED)
- [ ] All findings categorized and prioritized
- [ ] Report generated and reviewed
- [ ] PDF export verified
- [ ] Lead status updated to: REPORT_READY
- [ ] Delivery call scheduled (for paid packages)

## Delivery call agenda
1. [ ] Introduction and context (5 min)
2. [ ] Overall score and benchmark (5 min)
3. [ ] Key findings walkthrough (15 min)
4. [ ] Prioritized recommendations (10 min)
5. [ ] Questions and discussion (10 min)
6. [ ] Next steps and proposal (5 min)

## Post-delivery
- [ ] Lead status updated to: DELIVERED
- [ ] PDF delivered via email
- [ ] Follow-up scheduled (3-7 days)
- [ ] Case study created (if lead approves)
- [ ] Invoice sent (if applicable)

## Follow-up
- [ ] Day 3: Check if questions or clarifications needed
- [ ] Day 7: Ask about implementation progress
- [ ] Day 14: Offer implementation support or additional services
- [ ] Day 30: Full follow-up — improvements visible?
- [ ] If no response → move to LOST, add to re-engagement sequence
